# HAL Apprentice Management System

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite

## Features
- Apprentice Registration
- Apprentice Management
- Attendance Tracking
- Punch In / Punch Out System
- Dashboard

## How to Run

1. Install Python
2. Install requirements

pip install -r requirements.txt

3. Run application

python app.py

4. Open browser

http://127.0.0.1:5000
